# 潜水英语 · Dive Lingo

为 2027 春节泰国 AOW 潜水课程准备的英语每日学习应用：每天 10 分钟,覆盖 OW 复习、AOW 预习与泰国潜店实用表达。

线上版:https://dive-lingo.ok.kimi.link(主)· https://ivyandbonjuice.github.io/dive-lingo/(备用镜像,GitHub Pages)

## 功能

- **今日训练**:倒计时训练,翻卡自评 + 小测验(英译中 / 中译英 / 听力 / 拼写),进度以「深度计」呈现
- **345 条词条**:OW 复习 139(装备 / 技巧 / 安全规则 / 手势)+ AOW 预习 88(深潜 / 导航 / 专长 / 海洋环境)+ 实用表达 47(课程沟通 / 船上日常 / 紧急状况)+ 拓展包 71(高氧 Nitrox 18 / 自由潜 23 / 斯米兰船宿 30)
- **手势专项闪卡**:24 个水下手势,看中文想动作
- **听写模式**:听发音拼单词,支持慢速重听,拼错自动排进复习
- **闪电过筛**:有英文基础?按范围快速过词,已会的直接标掌握跳过,不熟的一键排进复习
- **弱词加练**:错得多、最不熟的词优先重练,不占用每日新词配额
- **学习设置**:每日新词量(5–30)、每次时长(5–20 分钟)、难度模式(轻松 / 标准 / 硬核)均可自定义;硬核模式把选择题升级为「看中文写英文」拼写题
- **间隔重复记忆**:Leitner 算法(1/2/4/8/15 天间隔),按设置量每日解锁新词
- **真人发音**:词条与例句全部预生成音频(m4a)随站点分发,任何手机浏览器(含微信内置)都能播放;Web Speech API 仅作兜底
- **潜伴进度名片**:生成只含昵称与进度数字的链接,潜伴打开确认后互相可见;默认分享不附带任何学习记录
- **学习记录**:连续天数、14 天曲线、分类掌握度、最常错榜单(localStorage 本地保存)
